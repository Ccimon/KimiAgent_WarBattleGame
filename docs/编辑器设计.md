# 编辑器架构设计(关卡编辑器 / 数值调参 / 无头模拟器)

> 状态:已实施(2026-08-11)。

## 1. 目标

玩法机制稳定后,为开发者提供内置工具链:可视化设计关卡、运行时调数值、批量模拟验证平衡。三者的公共前提是**数值配置化**——把 `game.ts` 顶部硬编码常量抽成运行时可写的 `CONFIG`。

## 2. 配置化(`src/config.ts`)

- `DEFAULT_CONFIG` 收纳全部可调数值:出兵/AP/速度/遭遇战/矿塔光环/转型消耗、`levelStats`(等级产速/上限)、`kindMods`(塔类型倍率)、`aiPersonalities`(AI 性格表)。
- `CONFIG` 为可变单例(初始 = `DEFAULT_CONFIG` 深拷贝),`game.ts`/`render.ts`/`main.ts` 一律在函数内运行时读 `CONFIG.xxx`,不调模块级缓存——面板改动下一帧即生效。
- `resetConfig()` / `applyConfig(patch)` 均为**原地深合并**,保持 `CONFIG` 引用稳定;`applyConfig` 支持只给部分字段。
- `TOWER_RADIUS` 留在 `game.ts`(渲染尺寸,非平衡数值)。
- 配套小重构:`update()` 的 AI tick 从硬编码 `['ai1','ai2']` 改为遍历 `Object.keys(state.aiTraits)`,模拟器因此能让 AI 接管任意势力(含蓝方);`checkPhase` 胜负语义不变。

## 3. 关卡编辑器(`src/editor.ts`)

- 入口:大厅「关卡编辑器」按钮,`mode = 'editor'`;画布复用 `draw()` 渲染(编辑内容经 `createGame` 重建为静态 `GameState`),选中圈/连线预览在 `draw()` 后叠加(`editorDraw`)。
- **坐标约定**:永远编辑横版 960×600 原始坐标;竖屏显示时经 `toPortrait` 转置,指针坐标反向交换 x/y 还原(`toRaw`),与"关卡只按横版设计"的既有约定一致。
- 工具:选择(点选 + 拖动移塔,**吸附 10px 网格**——现有关卡坐标都是 10 的倍数,坐标夹在塔半径内)、加塔(点空白,默认中立/10 兵/普通,同样吸附)、连线(A 拖到 B,toggle 边;**按住道路中段拖出弯折点即曲线道路**,弯折点吸附网格、以小圆点显示,点击已有弯折点不拖动 = 删除,删光退回直线边)、删除(点塔删除,关联边删除且其余边下标前移)。
- 属性面板(左侧,选中塔时):势力/初始兵力/**坐标 x/y 直填**(不吸附,供精细微调)/塔类型,可删除此塔;工具栏右侧实时显示指针(吸附后)的横版原始坐标。
- 关卡下拉:新建关卡,或载入现有关卡副本编辑;工作副本保存在模块内,试玩往返不丢。
- 试玩:当前编辑内容开一局 solo(`playtestDef`),HUD 显示「返回编辑器」替代关卡流转按钮;横竖屏切换时按试玩关卡重载。
- 导出:生成与 `levels.ts` 手写风格一致的 `LevelDef` 代码片段(2 空格缩进,`kind` 缺省不输出),textarea 展示 + 剪贴板复制;无蓝方塔或无 AI 塔时警告(不硬阻断)。

## 4. 数值调参面板(`src/tuning.ts`)

- 编辑器工具栏「数值」页签(右侧抽屉),schema 驱动:每组字段(点路径 + 中文标签 + min/max/step)自动生成 滑杆 + 数字输入,改动即写 `CONFIG`。
- 分组:全局、`levelStats` 各级、`kindMods` 各类型、`aiPersonalities` 各性格(`huntStrong` 为勾选;`order` 优先级数组不在面板编辑)。
- 按钮:恢复默认、复制配置代码(`JSON.stringify(CONFIG, null, 2)` 即合法 TS,整体替换 `DEFAULT_CONFIG` 的值定稿)、导入 JSON(部分字段深合并)。
- 配置只存内存,不写 localStorage;刷新即回默认,定稿靠贴代码。

## 5. 无头模拟器(`sim/simulate.ts`)

- `npm run sim -- [关卡号1-9] [局数] [配置JSON路径]`,默认第 4 关 100 局;`tsx` 直接跑 TS,无需构建。
- 全员 AI:开局对所有参赛势力(含蓝方)`assignAi`;固定步长 `dt=0.1`,单局上限 900 秒。
- 判胜不看 `phase`(其语义以真人蓝方为基准,蓝方全灭会冻结 `update`),直接统计存活势力(塔 + 行军队伍),只剩一方即终局;循环里每 tick 强制 `phase='playing'` 续跑。
- 输出各势力胜场/胜率、平均时长、超时平局数;第三参数挂配置 JSON 可对比调参前后胜率。

## 6. 基线数据(2026-08-11,默认配置)

- 第 4 关 × 100 局:蓝 4% / 红 49% / 紫 47%(全员 AI 时蓝方角落出生点明显劣势,真人玩蓝方不在此列)。
- 第 1 关 × 100 局:蓝 37% / 红 7% / 超时平局 56%(两方关 AI 容易僵局)。
